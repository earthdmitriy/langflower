Langflower palette

Normalized color schema and typography reference for the editor UI. Specimens use inline styles that imitate Tailwind default palette values. Copy the Tailwind classes from the HTML comments above each block into Angular templates.

Standalone file — no Tailwind CDN/build. Dark mode in the app is html[data-theme='dark'] with dark:* utilities (see packages/ui/docs/THEMES.md). This page shows light and dark side-by-side.

1. Semantic encoding

Encode Role Family Signal hex Forbidden
neutral Surfaces, default text, borders, default / ghost buttons, dividers zinc zinc-500 #71717a gray / slate / neutral mixes
success Run OK, affirmative actions, node/edge value emerald emerald-500 #10b981 green-*
error Failures, destructive confirm, node/edge error, error text rose rose-500 #f43f5e red-* for chrome
warning Pending / stop / interrupt, caution metadata, node pending amber amber-600 #d97706 yellow for chrome fills
info HITL / continue / resume, node hitl sky sky-500 #0ea5e9 cyan / blue for HITL
selection Selected node chrome / selection ring blue blue-500 #3b82f6 violet for selection
hover Feed ↔ canvas hover linkage only violet violet-500 #8b5cf6 violet for error/success
Deviations to retire in app code: text-red-700 / dark:text-red-300 (use rose); leftover class names lf-btn / lf-text-caption without CSS definitions — prefer Tailwind utilities from this file.

7. Work log / feed

Draft is a left chat bubble with markdown as soon as tokens arrive. On tool / subagent the open draft closes, a borderless collapsed log appears, then a new draft bubble continues. When the turn completes, draft and streaming… disappear — only the content bubble remains. Hover = hover · violet; live cues = warning · amber. Docs lock: features/feed-panel.md · epic 34.
