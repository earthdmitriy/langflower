# Langflower logo — image-generator prompts

## Brief

Langflower turns local folders into repeatable AI workflows. Its visual
metaphor is **flow → flower**: a five-stage graph whose cycle forms abstract
flower petals.

The mark must communicate a visible, controllable process — not a generic
chatbot, a gardening product, or an eco brand.

### Core workflow

`Plan → Refine → Dev → QA → Review → Plan`

The centre represents the local workspace: its files, data, and durable
session. A small gate on one edge may represent human approval.

### Universal constraints

Append these constraints to every prompt:

> Minimal vector identity, flat geometric shapes, strong silhouette at 16px,
> no gradients, no shadows, no 3D, no text, no letters, no literal flower
> petals, no leaf, no stem, no chatbot face, no brain, no robot, no cloud,
> no code brackets, no generic AI sparkle. White or transparent background.
> Suitable for a dark technical product UI and monochrome reproduction.

## Prompts

### 1. Recommended — cyclic graph flower

> Design a distinctive logo mark for “Langflower”, a local-first visual AI
> workflow tool. Create five abstract, angular petal-like segments around a
> compact central workspace node. The segments connect in a clockwise cycle,
> visibly suggesting Plan → Refine → Develop → QA → Review → Plan. The outer
> contour should read as a modern flower only after a second look; the primary
> read is a precise workflow graph. Include one small square checkpoint on a
> connection as a human approval gate. Technical, calm, and confident.

### 2. Graph-first, flower-second

> Create an abstract symbol for “Langflower”: five rounded graph nodes linked
> by directional edges in a closed cycle. Arrange the edges so their negative
> space forms a subtle five-petal flower around a central dot. It should look
> like developer tooling, not botanical illustration. Balance symmetry with a
> slight directional bias that makes the execution flow feel alive.

### 3. Local workspace centre

> Create a logo for a local workspace automation product called “Langflower”.
> Show a central square or folder-like core representing local files and data.
> Surround it with five orbiting workflow stages that form a restrained,
> geometric flower. The stages must be visibly connected into a repeatable
> loop; one connection includes a clear human decision gate. The result should
> suggest control, continuity, and work that survives a reopened browser tab.

### 4. Monochrome app icon

> Design a one-color app icon for “Langflower”, a visual workflow harness.
> Use five interlocking polygonal arcs arranged as an abstract flower and
> circular execution loop. Preserve a simple central point. Make it instantly
> recognisable in a 16px favicon and a 32px sidebar icon. The mark must work
> in solid black, solid white, and one accent color without internal detail
> disappearing.

### 5. Strict harness / controlled flow

> Create a bold abstract logo for “Langflower”. Depict a closed five-step
> workflow cycle as a flower-shaped mechanism: each petal is a defined stage,
> and each transition is deliberate and constrained. Add a tiny gate or lock
> motif only through geometry, not a literal padlock. It should communicate
> “the process is visible and cannot silently skip review.” Use clean
> engineering geometry with a welcoming, human-scale feel.

### 6. Softer, end-user-facing variant

> Create a friendly but technical logo for “Langflower”, software that helps
> people run repeatable AI workflows on files in a local folder. Form a simple
> five-petal abstraction from connected workflow lines, with a warm central
> workspace point. It should feel approachable enough for writers and
> researchers, yet structured enough for developers and QA teams. Avoid
> corporate cloud imagery and literal flowers.

## Color explorations

Generate each selected mark in these palettes after the monochrome shape is
approved:

1. **Graphite + orchid** — dark graphite structure, one muted violet accent.
2. **Ink + lime** — near-black structure, restrained yellow-green checkpoint.
3. **Midnight + coral** — deep navy structure, a single coral approval gate.
4. **Monochrome** — required baseline for icons, print, and dark/light themes.

The accent belongs on a single transition or gate, not on every petal. The
loop itself should remain readable without color.

## Selection criteria

- Reads as a workflow loop before it reads as a literal flower.
- Remains identifiable when reduced to 16px.
- Has no dependency on text, arrows too small to see, or a light background.
- Can become a loading/progress animation by rotating or illuminating one
  stage at a time.
- Does not resemble a generic LLM/chatbot logo or a no-code automation logo.

## YouTube video preview prompts

Format: **1280×720** YouTube thumbnail as a **colorful garden × high-tech
vector infographic** — nature-first mood (grass, stems, blossoms) with a
light tech HUD accent. Richer and more dimensional than flat UI posters;
still readable, not a busy photo-collage.

**Style rules (every prompt):**

- Base: polished vector illustration with soft depth — 2–3 tone shading,
  gentle glow on the active stage, subtle layered cards. Not photoreal;
  not gray ISO-flat.
- Nature (primary): petal-nodes, stem/vine edges, grass ground, clover or
  small wildflower accents, pollen-gold highlights. The frame should feel
  associated with a cultivated meadow/garden.
- High-tech (secondary accent only): thin cyan circuit traces along a few
  stems, corner HUD brackets, tiny hex/dot grid behind the hero, status
  pips. Restrained — tech supports the garden graph, does not dominate.
- Contrast: ink on cream or cream on deep leaf; saturated stage colors;
  dull gray only for “bad/old” chat side.
- Medium density: hero + ~3 callouts + short legend/footer. Breathing room
  at edges; no empty half-frame, no wallpaper of plants.

Typography: bold geometric sans; large titles; phone-readable stage labels.
Avoid robots, brains, chatbot faces, purple neon AI clichés, heavy lens
flare, photoreal hands.

**Palette (lush garden + tech accent):**

- cream `#FFF6E8`, ink `#1A1A1A`, deep leaf `#145C38`, meadow `#3FAE6C`
- coral blossom `#FF5A4A`, petal pink `#F08ABA`, orchid `#8B5CB8`
- pollen gold `#F2C14E`, soft sky `#5BB4E8`
- tech cyan `#2EE6A6` (glows, circuit lines, HUD ticks only)
