### BUG-2026-07-15b — execution chrome missing after a mid-run browser reload (direct-DOM reflection races the async canvas paint)

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**               | 2026-07-15                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Area**               | execution · ui · canvas                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Symptom**            | With a run in flight, reload the browser tab (`session.state.snapshot` replays `executionFeed`). After reconnect the work-log feed shows the run correctly, but the canvas wires/nodes are **not** highlighted — they stay `idle` even though `WorkflowExecutionService` has replayed the output states into its signals. (BUG CASE 2.)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Repro**              | Open the editor, run `constant → router → delay(1000) → preview`. While the delay is pending, reload the tab. The canvas shows no working/pending chrome on the wires; the feed does. The same chrome worked fine on a fresh run (no reload), because then the events arrived after ng-diagram had already painted the elements.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Root cause**         | `FlowCanvasComponent.applyExecutionChrome()` reflected the shared execution state onto the canvas DOM by a **direct-DOM query** (`host.querySelectorAll('.lf-node-chrome[data-node-id]')` / `ng-diagram-edge[data-edge-id]`) driven from the bridge event subscriptions. It relied on the elements already existing in the DOM at the moment the event fired. On reconnect the snapshot event arrives **before** ng-diagram paints the nodes/edges, so the query found nothing and the chrome was never applied; nothing re-ran the reflection afterwards, so it stayed blank. This is a second instance of the same signal-as-DOM-load problem as BUG CASE 1: observability (here, the chrome paint) was coupled to a side-channel (event timing) instead of the actual render/state. The required pulse (a transient green flash) was also driven through a separate `ExecutionAnimationService` that emitted `highlight`/`clear` intents the canvas applied by yet another DOM query — the same race, plus an extra service. |
| **Fix**                | Removed `applyExecutionChrome` and `ExecutionAnimationService` entirely. Chrome is now **signals-native and self-contained per element**: `LfNodeComponent` reads `execution.nodeStatus(id)` (a `computed`) and binds `lf-node-chrome--pending/--value/--error`; a new `LfEdgeChromeComponent` (`NgDiagramEdgeTemplate`) reads `execution.wireStatus(id)` and binds `lf-edge--pending/--value/--error`. Because each element binds its own chrome from the reduced signal on its **first** render, the colour appears as soon as ng-diagram paints the element — no canvas-wide DOM sweep, no timing dependency. The transient pulse moved into each component, driven by a per-element filtered stream (`WorkflowExecutionService.getEventsForNode(id)` / `getEventsForEdge(id)` over `runner.output-emitted`), so it fires only on a live `value` and never re-fires on replay. Edges now carry `type: 'lf-edge'` so ng-diagram uses the custom template.                                                                     |
| **Design flaw signal** | **Reduce state once, project it per element — never re-derive it from a global side effect against a possibly-empty DOM.** A canvas-wide "reflect signals into the DOM by querySelector" routine is inherently racy against asynchronously-painted elements (and against reconnect, where the state event pre-dates the paint). Put the projection where the element is created (the component's template binding / `computed`), so it is correct on first paint and stays correct under replay. The same lesson applies to the pulse: drive transient flashes from a per-element event slice, not a separate service that re-introduces the same DOM-query race.                                                                                                                                                                                                                                                                                                                                                               |
| **Regression test**    | `packages/ui/src/app/features/canvas/tests/lf-node-chrome.test.ts` (asserts `lf-node-chrome--pending/--value/--error` and the `--pulse` flash render from the reduced signal) and `packages/ui/src/app/features/canvas/tests/lf-edge-chrome.test.ts` (asserts `lf-edge--pending` / `--value` and `--pulse`); snapshot replay: `packages/ui/src/app/services/tests/execution-chrome-fold.test.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
