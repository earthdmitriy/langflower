### BUG-2026-07-15 — bypass ports (Router) never emit `output-emitted`, so downstream wires never highlight

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**               | 2026-07-15                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Area**               | execution · runtime · ui                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Symptom**            | Wire from a Router (bypass-only) to a Preview/sink node never shows the "working" (pending / dark-yellow) highlight while the run is in flight; it stays `idle`. Same for any edge whose source is a bypass output.                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Repro**              | Build `constant → router(ch) → preview`. Run and inspect the `runner.output-emitted` stream: the router's `ch` output emits nothing — only the downstream sink emits. `WorkflowExecutionService.edgeStates` never receives an `edgeId` for the router→sink edge, so `wireStatus` stays `'idle'`.                                                                                                                                                                                                                                                                                                                          |
| **Root cause**         | In `runtime-runner.ts` `runScope`, the source for a bypass edge was resolved via `getBypassConnection(...)` **raw**, while the telemetry tap (`watchedByKey`) wrapping the same bypass output was built but never wired into the dataflow. Bypass ports were deliberately connected raw "to avoid StatefulObservable loading semantics on a pure forward" — but that also suppressed all `output-emitted` telemetry, so `edgeIds` for bypass-sourced edges were never pushed. The pre-pass also hardcoded `slotIndex = 0` when building the tap, so multi-slot bypass ports wrapped the wrong slot connection.            |
| **Fix**                | `runScope` now prefers the `watchedByKey` tapped wrapper for bypass sources (same path as regular ports), so `output-emitted` rides the dataflow and fires as part of delivery; it falls back to the raw connection only when no tap was built for that slot. The tap build loop now uses the slot's actual `slotIndex` (via `parseSlotKey`) instead of a hardcoded `0`, so per-slot bypass telemetry is correct. Each `output-emitted` now carries `edgeIds` for every outgoing wire of the bypass port. The UI already renders whatever `edgeId` states it receives, so the wire highlights without further UI changes. |
| **Design flaw signal** | **Telemetry coupled to the connection strategy, not the dataflow.** "Pure forward" (raw bypass connect) was treated as mutually exclusive with telemetry, so choosing raw silently dropped observability. Telemetry should ride the dataflow path (a `pipe(tap)` that mirrors the source's loading) regardless of whether the port is bypass or regular — wrapping with `pipe(tap).with({ meta })` does not inject new loading semantics, so the bypass-vs-regular distinction was a false dichotomy for observability.                                                                                                   |
| **Regression test**    | `packages/runtime/src/testing/workflows/router.workflow.test.ts` — `emits output-emitted telemetry with edgeIds for bypass outputs (BUG CASE 1)`: the router's `output-emitted` events exist and each carries the outgoing edge ids.                                                                                                                                                                                                                                                                                                                                                                                      |
