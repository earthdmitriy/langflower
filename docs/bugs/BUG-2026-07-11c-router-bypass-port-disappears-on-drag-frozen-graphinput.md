### BUG-2026-07-11c — router bypass port disappears on drag (frozen `graphInput` snapshot)

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**               | 2026-07-11                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Area**               | ui · canvas                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Symptom**            | Wire a new edge to a `common-router` node's bypass port (empty trailing slot appears, correct). Drag the router node afterwards → the empty slot silently disappears.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Repro**              | Load example workflow → wire an edge into the router's bypass channel → drag the router node → the trailing empty bypass slot is gone. See regression test in `dynamic-port-update.test.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Root cause**         | `editor.addEdges` patched the _live_ diagram node's `data.ports` via `buildDynamicPortUpdates` (BUG-2026-07-11's fix). But `editor.updateNodes` (fired by the drag → `editor.updateNode.requested` → server round trip) rebuilt that same node's ports via `persistedNodeToDiagram(node, palette, this.graphInput().edges)`. **`graphInput` is only the initial slice of the workflow, captured once from the first `workflow.current.snapshot` push at canvas mount — it is never refreshed by incremental `editor.addEdges`/`editor.deleteEdges` deltas.** So the rebuild silently reverted the patch applied one step earlier, using an edge list from _before_ the new edge existed. This is a structural staleness bug, not a one-off: two independent code paths (`buildDynamicPortUpdates` on live `Edge[]` vs. `resolveNodePorts` on frozen `graphInput().edges`) computed the same "real ports + 1 free slot" data from different, divergent sources, and any node-level update silently clobbered the first path's work. |
| **Fix**                | Deleted the entire client-side port-patch pipeline (`buildDynamicPortUpdates` and ~15 helpers in `bridge-diagram.service.ts`, `applyDynamicPortUpdates` in `flow-canvas.component.ts`). `LfNodeComponent` now derives `inputPortRows`/`outputPortRows`/`bypassPortRows` via `computed()`s reading `resolveNodePorts(portsConfig, nodeId, connectedEdges())`, where `connectedEdges` filters the **live** `NgDiagramModelService.edges()` signal by node id — recomputed automatically on every edge or node mutation, so nothing is cached on node `data` that can go stale. `persistedNodeToDiagram` no longer takes an `edges` argument or resolves ports at all. Added a doc comment on `FlowCanvasComponent.graphInput` and dedicated sections in `docs/architecture/ui/NG_DIAGRAM.md` / `packages/ui/docs/DIAGRAM_CANVAS.md` spelling out that `graphInput` is init-only.                                                                                                                                                     |
| **Design flaw signal** | **Frozen init-time snapshot read as if it were live state.** `graphInput` (`WorkflowPersistedGraph`, an `input.required<>()`) is bound once at mount and never updated by subsequent deltas, but nothing marked it as such — a second code path reached for it well after init, assuming it tracked current state. Whenever a component receives an initial data snapshot _and_ separately subscribes to incremental deltas for the same domain, the snapshot must either be explicitly one-shot-consumed (as here, only inside the seeding `computed()`) or actively kept in sync — never both "kept around" and "read elsewhere" without an explicit contract. This generalizes beyond ports: any future code reading `graphInput()` for "current" nodes/edges will reintroduce this exact class of bug.                                                                                                                                                                                                                         |
| **Regression test**    | `packages/ui/src/app/features/canvas/tests/dynamic-port-update.test.ts` — "keeps the trailing empty bypass slot after an unrelated node update (drag)"                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
