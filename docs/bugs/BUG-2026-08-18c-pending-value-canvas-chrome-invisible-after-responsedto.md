### BUG-2026-08-18c — Pending/value canvas chrome invisible after ResponseDto pulse

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**               | 2026-08-18                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Area**               | ui · canvas                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Symptom**            | Starting a graph such as string → review-gate: short green blinks on both nodes, then no colour until the gate finished. NDJSON showed `runner.port` `{ pending: true }` on string `value` and gate `ok`/`fail`.                                                                                                                                                                                                                                                              |
| **Repro**              | Run test review-gate. Watch canvas: pulse, then idle borders/wires, then green when `ok` or `fail` emits `{ value }`.                                                                                                                                                                                                                                                                                                                                                         |
| **Root cause**         | Folds already stored ResponseDto (`'pending' in` / `'value' in`). Paint lost: (1) ng-diagram path reads `--edge-stroke`, but pending/value/error only set `path { stroke }` in `styles.scss`; pulse animation ended at idle gray `#a1a1aa`. (2) node `--pending`/`--value` `border-color` lost to Tailwind `border-zinc-300` / `dark:border-zinc-700`. (3) node `pulse$` treated input `{ value }` as a delivered output, so the gate flashed green instead of staying amber. |
| **Fix**                | Host `--edge-stroke` / `--ngd-default-edge-stroke` on `lf-edge--pending\|value\|error` (same as selected). Pulse 100% fades to `var(--edge-stroke)`. Idle/status node `border-color` only in `node-port-layout.css`. Node pulse is `out` + `'value' in` DTO.                                                                                                                                                                                                                  |
| **Design flaw signal** | Classes on the host are not paint. Custom edge templates must set the CSS variables the path actually reads. Status colour cannot share an element with utility `border-*` colours. Pulse is an output-value flash, not “any `{ value }` on the node”.                                                                                                                                                                                                                        |
| **Regression test**    | `canvas-node-status-projection.test.ts` (string value / gate pending); `execution-chrome-fold.test.ts` (trigger value + ok/fail pending); `lf-edge-chrome.test.ts` (`--edge-stroke` on pending/value); `lf-node-chrome.test.ts` (no pulse on input value or output pending)                                                                                                                                                                                                   |
