### BUG-2026-07-15c — `@rx-evo` has no public merge-of-`raw$` primitive; `statefulObservable({ input })` re-subscribes a stream on every emission

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**               | 2026-07-15                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Area**               | execution · runtime                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Status**             | fixed (v1: values only); full `raw$` blocked on `@rx-evo` (documented on `PortMeta.mode: 'merge'`, 2026-07-22)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Symptom**            | `multi: 'merge'` input ports were collapsed with `'combine'` into one code path that always produced a `combineLatest` **array**, so `common-merge` forwarded `[x]` instead of `x`. When implementing a true flatten, the obvious `statefulObservable(merge(...sources.value$))` (passing the merged stream as `input`) produced a `StatefulObservable` whose `value$` never terminated (5000 ms test timeout) — every emission of the input stream re-triggered `@rx-evo`'s `combineLatest([source$, cache$]) → switchMap(loader)` machinery, re-subscribing the stream.                                                                                                                                                                                                   |
| **Repro**              | In `runtime-runner.ts` `multyInputGroups` post-loop, build the merge source as `statefulObservable(merge(...sources.map((s) => s.value$)))` and read its `value$` with `toArray()` → hangs. Build it as `statefulObservable({ loader: () => merge(...sources.value$) })` instead → terminates with the flattened values.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Root cause**         | `@rx-evo/stateful-observable` treats `input` as a **single** value (a param / seed), not a stream: its constructor does `combineLatest([source$, cache$]).pipe(switchMap(loader))` and re-runs the loader on each `source$` emission. Passing a multi-emission `Observable` as `input` makes it treat each element as a fresh seed and re-subscribe. The only public fan-in combinator is `combineStatefulObservables` (combineLatest → array). A `merge`-of-`raw$` combinator does not exist, and the `raw$`→`StatefulObservable` wrapper (`fillStatefulObservable`) is **internal/unexported**, so there is no public way to build a `StatefulObservable` from an arbitrary `raw$` stream (which is what full state forwarding — loading/error/inactive — would require). |
| **Fix**                | `multyInputGroups` now branches on `inputMeta.mode`: `'combine'` keeps `combineStatefulObservables(sources, v => v)` (array); `'merge'` flattens success values via `statefulObservable({ loader: () => merge(...sources.value$) })`. The `common-merge` node is unchanged (passthrough of the merged connection). `join-node` test harness switched from `mode: 'merge'` to `mode: 'combine'` (array-join is inherently combineLatest). New `merge-node` harness + test assert flatten (`['foo','bar']`, not `['foo']`/`[['foo'],['bar']]`). Full `raw$` passthrough waits on `@rx-evo`; limitation documented in `packages/runtime/src/types.ts` § Multi-input ports.                                                                                                     |
| **Design flaw signal** | **Streaming fan-in (merge) is not expressible with the public reactive API.** A `StatefulObservable` is entirely defined by its `raw$`, yet the library only lets you construct one from a `loader`/single-`input` — and `input` is semantically a value, not a stream. Any node that must flatten multiple reactive inputs, or forward non-success states, hits an API gap and must either misuse `input` (re-subscription bug) or reimplement the unexported `fillStatefulObservable`. Candidate ADR / principle: `@rx-evo` should expose a `mergeStatefulObservables(raw$)` (or export `fillStatefulObservable`) so runtime fan-in can forward full `ResponseWithStatus` state without duplication.                                                                      |
| **Regression test**    | `packages/runtime/src/testing/nodes/merge-node.test.ts` — merge flattens multi-input values (one emission per source, not an array) and rejects duplicate edges; `join-node.test.ts` still asserts combineLatest array join.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
