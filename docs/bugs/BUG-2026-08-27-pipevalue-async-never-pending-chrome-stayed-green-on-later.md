### BUG-2026-08-27 — `pipeValue` + async never pending; chrome stayed green on later waits

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Date**               | 2026-08-27                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Area**               | common-nodes · node-sdk · canvas · ws                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Symptom**            | Delay (and other catalog waits: files, HTTP, LLM feedback turns, HITL Review Gate) stayed **green** after the first success. Repeat→Delay ticks 2–N never showed working chrome. `runner.port` had no `{ pending: true }` on those activations.                                                                                                                                                                                                                                |
| **Repro**              | Number → Repeat(count 4) → Delay(3000ms) → Repeat.trigger. Tick 1 goes amber then green; ticks 2–4 stay green for the whole wait. Same for LLM turn 2 after a finished `result`.                                                                                                                                                                                                                                                                                               |
| **Root cause**         | `pipeValue` forwards loading but **does not create it**. `concatMap(delay)` / `from(Promise)` / HTTP / `switchMap(runSession)` only delay the success lane. Canvas `appendNodeChromeFrame` also ignored **output** `{ pending: true }` after a settled value (`hasNonStreamingValue` stayed true), so even a correct pending would have left the node green.                                                                                                                   |
| **Fix**                | SDK `withLoading()` on the raw SO stream before async `pipeValue` (Delay / files / crawl / embed / MCP); `defineNode` bakes the same stamp before `execute`; LLM cycle pending **per turn** via `statefulObservable` + `concatMap` (not `pipeValue`, which would cancel in-flight turns); Sub-Agent pending **per invoke** (not per token); Review Gate `response`/`feedback` pending until HITL. Chrome fold clears settled green on `out` pending. Feed still drops pending. |
| **Design flaw signal** | Async wait is not a value transform. Loading belongs on `.pipe(withLoading())` before `pipeValue` work (timer / HTTP / HITL wait), or on a queued `concatMap` loader for LLM turns — not on the chunk stream (that re-pends every token through demux). UI folds that treat “has a value” as terminal miss later waits on the same port.                                                                                                                                       |
| **Regression test**    | `packages/common-nodes/src/flow/delay/node.test.ts`; `packages/node-sdk/.../define-node/test/samples/samples.test.ts` (async `execute` pending); `packages/ui/.../canvas-node-status-projection.test.ts` (out pending after green); `packages/common-nodes/src/ai/features/llm-session/llm-session-shell.test.ts`; `packages/common-nodes/src/hitl/review-gate/node.test.ts`; `tests/integration/ws/pending-events-bridge.ws.test.ts` (pending after Delay `in` value)         |
