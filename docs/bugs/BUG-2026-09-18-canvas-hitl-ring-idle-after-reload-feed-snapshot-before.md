### BUG-2026-09-18 — Canvas HITL ring idle after reload (feed snapshot before palette)

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**               | 2026-09-18                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Area**               | ui · canvas · hitl                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Symptom**            | Live HITL paints the node ring. After tab reload the ring stays idle even though the feed snapshot still has the waiting `input-received`.                                                                                                                                                                                                                                                                                              |
| **Repro**              | Start a HITL wait (wired non-HITL input on an LLM node). Reload while the session still has `executionFeed.snapshot`. Live path OK; reconnect path `awaiting === false`.                                                                                                                                                                                                                                                                |
| **Root cause**         | Bootstrap emits `executionFeed.snapshot` before `palette.snapshot`. HITL chrome replay with `catalog === null` stores events but leaves `awaiting` false. The first catalog action then **skipped** `rebuildNodeHitlAwaitState` because `composer.catalog === null`. Status chrome rebuilds whenever events exist; HITL chrome did not. Same false-ready class as BUG-2026-07-21b, on the catalog branch instead of `startWith(empty)`. |
| **Fix**                | Catalog action rebuilds from stored events whenever `events.length > 0`, matching `fold-canvas-node-status.ts`.                                                                                                                                                                                                                                                                                                                         |
| **Design flaw signal** | **Asymmetric catalog hydrate.** A one-shot snapshot that cannot classify yet must re-fold when defs arrive. Guarding rebuild on “we already had a catalog” drops the first real catalog after a null hydrate. Copy the status-fold catalog branch: skip only when there are no events.                                                                                                                                                  |
| **Regression test**    | `packages/ui/src/app/features/canvas-node-status-folding/tests/fold-canvas-node-hitl.test.ts` — snapshot-before-palette keeps `awaiting`                                                                                                                                                                                                                                                                                                |
