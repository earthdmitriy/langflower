### BUG-2026-07-16 — subscribing `WorkflowExecutionService` to `runner.snapshot` triggers NG0200 in standalone component tests

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Date**               | 2026-07-16                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Area**               | ui · hitl · ws                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Status**             | fixed (derive `isRunning` from run-lifecycle events instead)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Symptom**            | Full vitest `--unit` suite failed with `RuntimeError: NG0200: Circular dependency detected for WorkflowExecutionService` in every `TestBed` that declares a component injecting `WorkflowExecutionService` (`dynamic-port-update`, `lf-node-chrome`, `lf-edge-chrome`, `workflow-execution.service.test`). The `ngTokenPath` listed only `[WorkflowExecutionService]` — no second token — so the cycle was invisible from the DI graph.                                                                                                                            |
| **Repro**              | Add `this.bridge.raw['runner.snapshot'].subscribe(...)` inside the `WorkflowExecutionService` constructor (alongside the existing `runner.started`/`runner.done`/… subscriptions), build, run the canvas unit tests → NG0200. Remove that single subscription → all green. Confirmed by bisection: reverting the whole service file fixed it; re-adding every change except the `runner.snapshot` subscription kept it green; re-adding only the `runner.snapshot` subscription reproduced it.                                                                     |
| **Root cause**         | Angular JIT (vitest) computes injector scope for `providedIn: 'root'` services from the **module import graph**, not the constructor parameter list. `runner.snapshot` is the only _snapshot-style_ event key the service touched, and its payload type (`RunnerSnapshotPayload` → `@langflower/runtime` types) was the first time that particular runtime type was pulled into the service's load-order during those tests, surfacing a latent circular module-eval path through `@langflower/runtime` ↔ bridge config that the event-style keys did not trigger. |
| **Fix**                | `isRunning` is now derived purely from the run-lifecycle events (`runner.started` / `runner.startNode.started` → `true`, `runner.done` / `runner.interrupted` → `false`); the `runner.snapshot` subscription was removed from the constructor. Mid-flight reconnect (a run already `running` at connect time) is no longer reflected into `isRunning`, but the runtime re-emits `runner.started`/`runner.startNode.started` on connect for the in-flight run, so the gate still settles correctly.                                                                 |
| **Design flaw signal** | **Avoid eager `subscribe()` to snapshot-style bus keys inside a `providedIn: 'root'` service constructor when the same fact is reachable from event-style keys.** Snapshot keys pull a different type-load path that can surface latent JIT circular-import cycles invisible from DI params. Prefer deriving UI gates from the existing event stream; extend the protocol/projection instead of adding a new eager subscription that duplicates a fact already on the wire.                                                                                        |
| **Regression test**    | Component TestBeds (`lf-node-chrome`, `lf-edge-chrome`, `dynamic-port-update`) stub `runner.snapshot` + `runner.port`; the full `--unit` suite stays NG0200-free. No remaining `workflow-execution.service.test.ts`.                                                                                                                                                                                                                                                                                                                                               |
