### BUG-2026-07-23 — Inspector panel params silently dropped (`editor.updateNodes []`)

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Date**               | 2026-07-23                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Area**               | server · workflow · editor · inspector · ws                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Symptom**            | Changing Inspector panel numbers (`maxIterations`, `maxFeedbackTurns`) sent `editor.updateNode.requested` with the new params, but the server replied `editor.updateNodes: []` — values never stuck / saved. Reproduced while the workflow was **not** started (idle).                                                                                                                                                                           |
| **Repro**              | Open adversarial Proposer (`common-openai-llm`) while idle → edit Tool-loop max iterations / Max feedback turns → WS: request carries params, delta is `[]`.                                                                                                                                                                                                                                                                                     |
| **Root cause**         | Panel `params` patches incorrectly forced a full `bindWorkflowToSessionEditor`. Any rebind failure returned silent `[]` (no reason). Rebind fails whenever `RuntimeEditor.locked` — including session-idle / editor-locked desync — because `removeNode` is ignored and `addNode` then returns false. Params are session-document / next-run ctx seeds and do not need rebind. `isGraphLocked()` alone was a secondary / incomplete explanation. |
| **Fix**                | Params-only patches update the session document without rebind (idle and while `runnerStatus === 'running'`). Position / ui / inputs stay blocked when session-locked; inputs still rebind when unlocked.                                                                                                                                                                                                                                        |
| **Design flaw signal** | Authoring params were tied to topology rebind + dual locks (`runnerStatus` vs `editor.locked`) with a silent empty delta — Inspector looked editable, server dropped the intent.                                                                                                                                                                                                                                                                 |
| **Regression test**    | `packages/server/src/workflow/apply-editor-mutation.test.ts` (idle params; idle+editor.locked; running params; inputs still blocked); `tests/integration/ws/editor.ws.test.ts` (params delta)                                                                                                                                                                                                                                                    |
