### BUG-2026-06-17 — port info popover vertical anchor misaligned

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**               | 2026-06-17                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Area**               | ui · canvas                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Symptom**            | Port hover popover opened with the **top** of the Disconnect button aligned to the port dot instead of the button **center**; earlier attempts shifted the whole popover too high or too low.                                                                                                                                                                                                                                                                                                                                                                                                |
| **Repro**              | Hover a wired input or output port on a canvas node; observe Disconnect button vs port dot vertical alignment.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Root cause**         | Vertical placement used two CSS vars (`--lf-port-dot-center-y`, `--lf-port-popover-button-center-y`) but the button offset was measured on the Angular **component host** (`<lf-port-info-popover>`) while `top` / `transform` applied to the inner **`.lf-port-info-popover`** div. The host is a zero-height inline box at the port; the inner div is absolutely positioned — so `translateY` used the wrong reference and only ~half the needed offset (button top ≈ port center). Earlier iterations also centered the whole panel or double-counted `offsetTop` along the parent chain. |
| **Fix**                | Measure and set `--lf-port-popover-button-center-y` on `#popoverRoot` (same element as `transform`); clear `transform` on that element during measure; `display: contents` on the host. Port dot center still set on `.lf-port-hover-host` via `getBoundingClientRect`. Files: `lf-port-info-popover.component.ts`, `lf-port-hover-zone.component.ts`, `node-port-layout.css`.                                                                                                                                                                                                               |
| **Design flaw signal** | **Measurement target ≠ styled element** — with Angular wrapper hosts, layout/position CSS on template roots must use the same DOM node for JS measurement and for CSS variables that drive that layout.                                                                                                                                                                                                                                                                                                                                                                                      |
| **Regression test**    | `none` (visual canvas alignment; no stable DOM fixture for ng-diagram port dots)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
