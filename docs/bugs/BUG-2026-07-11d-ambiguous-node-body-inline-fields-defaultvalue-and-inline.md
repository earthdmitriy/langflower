### BUG-2026-07-11d — ambiguous node-body inline fields; `defaultValue` and inline number/boolean edits never coerced

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**               | 2026-07-11                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Area**               | ui · canvas · server · node-definitions                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Symptom**            | Three related issues in the old inline-editing path: (1) `DiagramInlineField` rendered node-body fields from `uiSchema` with no link to a specific input port, so a node with multiple inputs had no way to say _which_ input an inline field edited; (2) `InputParams.defaultValue` was declared on port configs but nothing ever read it into `node.inputs` on node creation, so unconnected inputs silently started as `undefined`; (3) editing a `number`/`boolean`-typed input inline persisted a **string** in `node.inputs`, since only `params` had server-side type coercion (`normalizeNodeParams`), not `inputs`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Repro**              | Add a `common-number`, leave `value` unconnected → `node.inputs.value` was `undefined` instead of the port's default. Edit that value inline → server stored `"1000"` (string) instead of `1000`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Root cause**         | Inline editing grew out of `uiSchema` (a node-level metadata array) instead of being a property of the port it edits, so the UI had to _guess_ the association between a body field and an input by name matching — this breaks as soon as a node has more than one editable input. Separately, `inputs` was added later than `params` and only partially mirrored its behavior: `defaultParamsFromDefinition`/`normalizeNodeParams` existed for `params`, but the equivalent `inputs` seeding/coercion was never written.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Fix**                | Deleted `DiagramInlineField`/`uiSchema`-driven body fields entirely. `InputParams.inline` is now a typed `InlineConfig` (`'text'` \| `'text-multiline'` \| `'boolean'` \| `'preview'` \| `'preview-markdown'` \| `'preview-code'` \| `{ type: 'select'\|'multiselect'\|'radio', options }`) that lives **on the port**, resolved by `resolveNodePorts` into `DiagramInputPortRow.inline`/`.value`/`.connected` and rendered by `lf-node-port-row` via `lf-inline-field.component.ts`. Portless literal nodes (`common-string`/`common-number`/`common-boolean`) were converted to a real `value` input port with `inline` set (no wire required) instead of a body field. Added `defaultInputsFromDefinition` (mirrors `defaultParamsFromDefinition`) and `normalizeNodeInputs` (mirrors `normalizeNodeParams`) in `apply-editor-mutation.ts`, applied on both `editor.addNode` and `editor.updateNode`. `inline: 'preview'` reads a live value from the new `NodePreviewValuesService`, which projects `runner.input-received` events — previously the Preview node's textarea had no execution-time data source at all beyond the wired-edge design-time value. |
| **Design flaw signal** | **Metadata attached to the wrong owner.** An editing affordance for an input's value was modeled as a node-level list (`uiSchema`) instead of a field on the input port it edits, so the UI layer had to reconstruct an association that the domain model should have carried directly. Also: **partial parity between two structurally identical fields** (`params` vs `inputs`) — whenever a new record-shaped field is added to mirror an existing one, grep for every helper on the original (`default*FromDefinition`, `normalize*`) and mirror all of them together, not just the parts exercised by the first feature that needed the new field.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Regression test**    | `packages/ui/src/app/diagram/tests/resolve-diagram-node-ports.test.ts` (inline/value/connected resolution), `packages/common-nodes/src/primitives/number/node.test.ts` (passthrough `value` input), `packages/server/src/workflow/apply-editor-mutation.test.ts` (`defaultInputsFromDefinition` / `normalizeNodeInputs`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
