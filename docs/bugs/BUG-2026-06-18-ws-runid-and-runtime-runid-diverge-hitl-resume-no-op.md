### BUG-2026-06-18 — WS runId and runtime runId diverge; HITL resume no-op

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**               | 2026-06-18                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Area**               | execution · server · runtime · ws · hitl                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Symptom**            | WS HITL flows time out after `execution.awaiting_input`: `execute.user_input` accepted but run never completes; integration tests fail on terminal `completed`. In-process runtime unit tests passed.                                                                                                                                                                                                                                                       |
| **Repro**              | 1) `execute.start` on a workflow with Agent → Ask User. 2) Wait for `execution.awaiting_input`. 3) `execute.user_input` with `runId` from WS ack. 4) Observe run hangs until client timeout.                                                                                                                                                                                                                                                                |
| **Root cause**         | `ws-handler.ts` generated a client `runId` and passed it to `WorkflowExecutorService`, but `workflow-runner.ts` always called `crypto.randomUUID()` for the runtime run. `resolveUserInput` required `activeRun.runId === runId`; mismatch meant `runtime.resumeUserInput` was skipped and only `userInputGateway.resolveUserInput` ran — the gateway promise is fire-and-forget and does **not** unblock `runtime.waitForUserInput()` on the hitl channel. |
| **Fix**                | Add optional `runId` to `WorkflowRunOptions`; pass `effectiveRunId` from `run-workflow-core.ts` into `runtime.run()`. Resume via `activeRun.resumeUserInput` when executor `activeRunId` matches (drop redundant runtime UUID check). Files: `packages/runtime/src/contracts.ts`, `packages/runtime/src/workflow-runner.ts`, `packages/server/src/runtime/run-workflow-core.ts`, `packages/server/src/services/workflow-executor.service.ts`.               |
| **Design flaw signal** | **Run identity was split across layers** — WS session id, executor session id, and runtime execution id were assumed equal without a single owner or propagation contract. HITL has two wait paths (gateway + runtime channel); only one was wired to resume.                                                                                                                                                                                               |
| **Regression test**    | Live HITL WS: `tests/integration/ws/execute-ask-user.ws.test.ts`, `execute-hitl-inputs.ws.test.ts`.                                                                                                                                                                                                                                                                                                                                                         |
