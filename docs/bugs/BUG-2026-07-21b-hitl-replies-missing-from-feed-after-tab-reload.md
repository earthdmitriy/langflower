### BUG-2026-07-21b — HITL replies missing from feed after tab reload

| Field                  | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**               | 2026-07-21                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Area**               | ui · hitl · feed · ws                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Status**             | fixed                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Symptom**            | During a live run, Review Gate / Ask User replies appear in the work log. After browser tab reload, sections return but nested HITL answer bubbles are gone.                                                                                                                                                                                                                                                                                            |
| **Repro**              | Run a HITL loop → submit feedback → reload tab while the session still has an `executionFeed`. Live path OK; reconnect path empty HITL bubbles. Unit: feed-before-palette in `execution-feed.service-replay.test.ts`.                                                                                                                                                                                                                                   |
| **Root cause**         | Bootstrap emits `executionFeed.snapshot` before `workflow.current.snapshot` / `palette.snapshot`. Feed fold used `withLatestFrom` on lookup maps that `startWith(empty)` — replay ran with no defs, skipped HITL `input-received`, and never re-applied when palette arrived. Awaiting-HITL fold already used `combineLatest` (tabs OK); feed fold did not.                                                                                             |
| **Fix**                | Gate feed snapshot actions on real workflow + palette Subjects via `combineLatest`, apply once per feed identity (`distinctUntilChanged` on the feed reference) so later catalog updates do not wipe live turns.                                                                                                                                                                                                                                        |
| **Design flaw signal** | **False-ready context** — `startWith(empty)` + `withLatestFrom` makes a one-shot snapshot hydrate look successful while classifying events with empty defs. Prefer `combineLatest` on raw catalog Subjects (or re-hydrate when defs arrive with a `live` gate). See [architecture/REACTIVITY.md](../architecture/REACTIVITY.md) § False-ready context.                                                                                                  |
| **Regression test**    | `packages/ui/src/app/features/feed-folding/tests/execution-feed.service-replay.test.ts` — `retains an early bridge snapshot until workflow and palette arrive`; canvas HITL: `packages/ui/src/app/features/canvas-node-status-folding/tests/fold-canvas-node-hitl.test.ts`; Run/chat-entry: `packages/ui/src/app/services/tests/chat-entry-clusters.test.ts` (`unknown types as non-chat-entry`). Do not recreate `workflow-execution.service.test.ts`. |
