# Project Summary: Langflower

## Purpose

Langflower is a reactive, visual programming environment designed for building complex LLM-based workflows. It allows users to compose modular components into fluid pipelines, balancing the power of automated reasoning with human intuition.

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS.
- **State Management**: Reactive signals/streams (Reactive Ports).
- **Core Engine**: Modular node-based architecture for composable logic.

## Core Philosophy

- **Declarative Flow**: Define _what_ happens rather than just _how_ it happens.
- **Human-in-the-Loop**: Seamless integration of manual checkpoints and feedback loops.
- **Composability**: Small, reusable "atoms" of logic that can be combined into complex "molecules."
