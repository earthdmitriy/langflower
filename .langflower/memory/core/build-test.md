# Build & Test

## Install

```bash
npm install
```

## Build

```bash
npm run build
```

## Typecheck

```bash
npm run typecheck
```

## Unit Tests

Run tests for specific packages (e.g., `common-nodes`):

```bash
npm test -- common-nodes
```

## Integration / Verification

Use the `eval` package to verify workflow performance and scoring:

```bash
npm run eval
```
